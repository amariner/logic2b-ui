# Logic2B UI — Style Reference
> quiet surfaces, one accent, type that does the work

**Theme:** light-first (dark mode fully supported)

Logic2B UI follows the Logic2B corporate identity used on
[logic2b.com](https://logic2b.com): a white canvas with flat grey surfaces,
hierarchy carried by size, grey text tones and generous space rather than
borders or shadows. Type is a single family — Inter Tight — with tight,
negative tracking that grows with the size. Headlines may run in two tones
(ink + `#8a8a8a`). The primary action is black; the only brand colour is the
Logic2B blue `#1466ff`, reserved for focus, selection and small signals.
Charts and the destructive state remain the only other chromatic colours.

## Brand assets

- **Isotype:** `apps/web/public/logo-mark.svg` (48-unit grid, solid black,
  `currentColor`-ready path). Favicon: `apps/web/public/favicon.svg` — the
  isotype in white on a black tile with an 11/48 radius.
- **Lockup:** isotype tile + the "Logic**2B** UI" wordmark set in Poppins
  (600 for "Logic", 800 for "2B", 600 grey for the "UI" product suffix). The
  wordmark only loads the subset glyphs in `apps/web/public/fonts`.
- **Brand colours:** ink `#000`, secondary text `#5e5e5e`, headline grey
  `#8a8a8a`, surfaces `#f4f4f4 → #ececec → #e4e4e4`, Logic2B blue `#1466ff`
  (`--brand` in `apps/web/src/styles/global.css`, site chrome only).
- **Social cards:** generated by `apps/web/scripts/generate-docs-og.mjs` in
  the same palette; the README banner lives in `.github/assets/banner.png`.

Component tokens below stay neutral on purpose: docs previews must look
exactly like what consumers install, so the brand lives in the site chrome,
not in the registry defaults.

palette mixes warm and cool stops per mode (see `apps/web/src/styles/global.css`).

Key signature: in dark mode the primary button is near-white with dark text —
a flash of brightness on the dark canvas. Depth never comes from shadows; it
comes from the luminance ladder and hairline borders.

## Tokens — Typography

### Inter Tight (`--font-heading` and `--font-sans`)
- **Role:** the whole interface. Headings (h1–h4) use tight tracking
  (-0.025em baseline; up to -0.04em at display sizes) and compressed
  line-height (0.95–1.1 at display sizes); body, navigation, controls and
  labels use regular weights. One family, differentiated by weight/tracking.
- **Weights:** variable 100–900; headings 600–700, UI text 400–600.
- Self-hosted variable subset (`/fonts/inter-tight-var-latin.woff2`) with
  `@fontsource-variable/inter` as fallback. `--font-heading` stays a
  separate token so a project (or the theme studio) can swap in a display
  family without touching components.

### Monospace (`--font-mono`)
- **Role:** code blocks, install commands, technical metadata. System stack
  (`ui-monospace, SFMono-Regular, Menlo, monospace`) — no webfont cost.

### Type scale (site)

| Role | Size | Line height | Tracking | Font |
|------|------|-------------|----------|------|
| caption | 12px | 1.2 | -0.01em | Inter Tight |
| body-sm | 14px | 1.4 | -0.006em | Inter Tight |
| body | 16px | 1.5 | -0.011em | Inter Tight |
| subheading | 20px | 1.3 | -0.02em | Inter Tight 600 |
| heading | 30–36px | 1.15 | -0.025em | Inter Tight 700 |
| display | 48–68px | 0.95–1.05 | -0.035em | Inter Tight 700 |

## Spacing, shape & elevation

- **Density:** compact controls, generous section rhythm. Section gap ~80px;
  element gap 8–12px; card padding 24–32px.
- **Radius:** `--radius: 0.625rem`; inputs/buttons derive `--radius-md`,
  cards `--radius-xl`. Tags and pills are fully rounded (`9999px`).
- **Elevation is luminance, not shadow.** Depth comes from the surface ladder
  and 1px hairline borders (`oklch(1 0 0 / 10%)` in dark). Box-shadows are
  reserved for overlays (popover, dialog, dropdown).

## Surfaces (light)

| Level | Token | Value | Purpose |
|-------|-------|-------|---------|
| 0 | `--background` | `oklch(1 0 0)` | Page canvas |
| 1 | `--secondary` / `--muted` / `--accent` | `oklch(0.97 0 0)` | Flat grey surfaces, hover states |
| 2 | `--border` / `--input` | `oklch(0.922 0 0)` | Hairlines where a surface is not enough |

## Do's and Don'ts

### Do
- Use Inter Tight for everything; keep tracking negative and line-height
  compressed at display sizes. Two-tone headlines (ink + grey) are welcome.
- Build hierarchy with size, grey tones and space before reaching for borders.
- Keep the primary action black (white in dark mode) and use it once per view.
- Use the Logic2B blue only for focus, selection and small status signals.
- Light is the default mode; dark must always remain first-class.
- Route every color through semantic tokens (`bg-primary`, `border-border`).

### Don't
- Don't introduce other chromatic accents in UI chrome. Color exists only in
  the brand blue, chart series and the destructive state.
- Don't use box-shadows on standard cards; reserve them for floating layers.
- Don't use warm or tinted grays; the neutral ramp is strictly achromatic.
- Don't redraw or recolour the isotype, and never replace it with arrows or
  generic glyphs.
- Don't set body text below 12px.

## Component treatments

- **Primary button:** near-black fill, white text (light mode); near-white
  fill, dark text (dark mode). The strongest element on screen.
- **Secondary/ghost:** recessed `--secondary` fill or transparent with hover
  lift to `--accent`.
- **Card:** `--card` surface, 1px `--border` hairline, no shadow.
- **Dialog/popover:** `--popover` surface — one luminance step above the
  canvas — with border and a restrained shadow.
- **Input:** `--input` hairline border; focus ring via `--ring`.

## Agent quick reference

- Text primary: `--foreground` · Text secondary: `--muted-foreground`
- Page: `--background` · Card/overlay: `--card` / `--popover` · Hover: `--accent`
- Primary action: `--primary` (near-white on dark, near-black on light)
- Focus: `--ring` · Hairline: `--border`
- Headings: `font-heading` (Inter Tight by default), tracking tight
- Brand accent: `--brand` (`#1466ff`), site chrome only
- Example hero: 60px Inter Tight 500, line-height 1, tracking -0.035em, ink
  with a grey second clause on the white canvas; below it one black
  `bg-primary` CTA and one ghost button.
