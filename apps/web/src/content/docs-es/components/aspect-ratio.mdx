## Uso

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"

<AspectRatio ratio={16 / 9}>
  <img src="..." alt="Imagen" className="rounded-md object-cover" />
</AspectRatio>
```

## Notas de uso

También acepta cualquier propiedad estándar de `div`, que se reenvía al
envoltorio.
