## Uso

```tsx
import { useState } from "react"
import { Calendar } from "@/components/ui/calendar"

const [date, setDate] = useState<Date | undefined>(new Date())

<Calendar mode="single" selected={date} onSelect={setDate} className="rounded-md border" />
```

Está construido sobre [react-day-picker](https://daypicker.dev). Consulta también el [selector de fecha](/docs/components/date-picker), una composición con Popover que convierte el calendario en un campo similar a una entrada de texto.

## Notas de uso

Se reenvían todas las demás propiedades `DayPicker` de [react-day-picker](https://daypicker.dev).
