## Accesibilidad

- Expone `role="checkbox"` y refleja el estado mediante `aria-checked`, incluido el estado mixto o indeterminado.
- <kbd>Espacio</kbd> alterna la casilla enfocada; <kbd>Tab</kbd> permite alcanzarla.
- Asocia un `Label` mediante un `htmlFor` que coincida con el `id` de la casilla para que el texto también active el control.
