## Uso

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"

<Collapsible>
  <CollapsibleTrigger>¿Puedo usarlo en mi proyecto?</CollapsibleTrigger>
  <CollapsibleContent>
    Sí. Puedes usarlo en proyectos personales y comerciales.
  </CollapsibleContent>
</Collapsible>
```

## Accesibilidad

- El activador expone `aria-expanded` y `aria-controls`, que apunta al contenido
  plegable.
- <kbd>Espacio</kbd> o <kbd>Intro</kbd> sobre el activador con foco alternan el
  panel.
- Cuando está contraído, el contenido queda oculto para las tecnologías de
  asistencia y sale del orden de tabulación.
