## Uso

```tsx
import { ColorPicker } from "@/components/ui/color-picker"

const [color, setColor] = React.useState("#3b82f6")

<ColorPicker value={color} onValueChange={setColor} />
```

Arrastra dentro del cuadrado para definir la saturación y el brillo, desplaza
la barra de tono para cambiarlo o escribe un valor hexadecimal directamente.
Emite una cadena `#rrggbb`, funciona por completo con el puntero y no añade
dependencias.
