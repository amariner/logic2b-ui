## Accesibilidad

- Construido sobre [Hover Card de Radix](https://www.radix-ui.com/primitives/docs/components/hover-card):
  se abre al pasar el puntero o al enfocar el activador con el teclado, por lo
  que se alcanza mediante <kbd>Tab</kbd>.
- Es una previsualización complementaria para personas videntes. No atrapa el
  foco ni se anuncia como diálogo, así que nunca debe contener en exclusiva
  información o acciones esenciales.
- <kbd>Esc</kbd> cierra una tarjeta abierta.
