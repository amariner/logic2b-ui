## Uso

```tsx
import { Input } from "@/components/ui/input"

<Input type="email" placeholder="Correo electrónico" />
```

Admite todos los tipos de entrada nativos, incluido `file`, y aplica estilos de estado no válido mediante `aria-invalid`.

## Notas de uso

`Input` renderiza un `<input>` nativo y reenvía todos sus atributos estándar (`React.ComponentProps<"input">`).
