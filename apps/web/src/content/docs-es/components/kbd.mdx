## Uso

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"

<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## Notas de uso

Ambos generan elementos sencillos —`Kbd` un `<kbd>` y `KbdGroup` un `<div>`— y
reenvían todos los atributos nativos. Usa `KbdGroup` para distribuir una
combinación de varias teclas.
