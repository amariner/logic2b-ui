## Uso

```tsx
import { Label } from "@/components/ui/label"

<Label htmlFor="email">Tu dirección de correo</Label>
```

## Notas de uso

`Label` reenvía todas las propiedades a `Label.Root` de Radix, que renderiza
un `<label>` nativo, por lo que admite los atributos estándar de una etiqueta.

También aplica automáticamente los estilos `peer-disabled` y
`group-data-[disabled=true]` cuando se coloca junto a un control desactivado.
