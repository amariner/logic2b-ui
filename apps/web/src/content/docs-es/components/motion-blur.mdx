## Uso

```tsx
import { MotionBlur } from "@/components/ui/motion-blur"

<MotionBlur duration={700}>
  <h2>Entra en foco</h2>
</MotionBlur>
```

`MotionBlur` equivale a `<Motion preset="blur">`. Consulta
[Movimiento](/es/docs/components/motion) para las propiedades compartidas
`duration`, `delay`, `hover` y `asChild`, las recetas de salida y el
comportamiento con movimiento reducido. Combina especialmente bien con una
`duration` más larga en encabezados y textos hero.
