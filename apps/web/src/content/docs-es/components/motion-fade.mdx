## Uso

```tsx
import { MotionFade } from "@/components/ui/motion-fade"

<MotionFade duration={600}>
  <Card>…</Card>
</MotionFade>
```

`MotionFade` equivale a `<Motion preset="fade">`. Consulta
[Movimiento](/es/docs/components/motion) para las propiedades compartidas
`duration`, `delay`, `hover` y `asChild`, las recetas de salida y el
comportamiento con movimiento reducido.
