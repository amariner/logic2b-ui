## Uso

```tsx
import { MotionSlide } from "@/components/ui/motion-slide"

<MotionSlide direction="up" delay={80}>
  <Card>…</Card>
</MotionSlide>
```

`MotionSlide` asigna `direction` al preset `fade-*` correspondiente de
[Movimiento](/es/docs/components/motion), como `up` a `fade-up`, y comparte las
propiedades `duration`, `delay`, `hover` y `asChild`.
