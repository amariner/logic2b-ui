## Accesibilidad

Está construido sobre el
[Navigation Menu de Radix](https://www.radix-ui.com/primitives/docs/components/navigation-menu).

- Los disparadores reciben el foco; <kbd>Intro</kbd>/<kbd>Espacio</kbd> y las
  flechas abren el menú y desplazan la selección.
- <kbd>Escape</kbd> cierra el panel abierto y devuelve el foco al disparador.
- El enlace activo usa `data-active`, que se asocia a `aria-current`, para que
  los lectores de pantalla anuncien la página actual.
- Cada panel de contenido queda etiquetado por su disparador.
