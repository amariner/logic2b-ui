## Accesibilidad

Está construido sobre [Radio Group de Radix](https://www.radix-ui.com/primitives/docs/components/radio-group) y sigue el patrón WAI-ARIA `radiogroup`.

- Las flechas mueven y seleccionan opciones; solo un elemento puede estar marcado a la vez.
- Se llega al grupo con <kbd>Tab</kbd>; el foco cae sobre la opción marcada o sobre la primera si no hay ninguna seleccionada.
- Asocia cada `RadioGroupItem` con un `Label` mediante valores coincidentes de `id` y `htmlFor` para que el área interactiva y el nombre accesible sean correctos.
