
## Notas de uso

Genera el `Loader2Icon` de `lucide-react` con `animate-spin` y reenvía cualquier
propiedad aceptada por un elemento `<svg>`, como `className` para cambiar tamaño
o color. Incluye `role="status"` y `aria-label="Loading"` para que las
tecnologías de asistencia lo anuncien.
