## Accesibilidad

- Expone el rol `switch` y comunica su estado activado o desactivado a las tecnologías de asistencia.
- Se alterna con <kbd>Espacio</kbd> o <kbd>Enter</kbd> cuando tiene el foco y se alcanza con <kbd>Tab</kbd>.
- Asocia un `Label` mediante `htmlFor`, o envuelve el control, para darle un nombre accesible.
