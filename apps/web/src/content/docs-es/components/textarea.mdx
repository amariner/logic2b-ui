## Uso

```tsx
import { Textarea } from "@/components/ui/textarea"

<Textarea placeholder="Escribe tu mensaje." />
```

## Notas de uso

`Textarea` renderiza un `<textarea>` nativo y reenvía todas sus propiedades. Ajusta automáticamente su altura al contenido mediante `field-sizing-content` y aplica estilos de validación cuando recibe `aria-invalid`.
