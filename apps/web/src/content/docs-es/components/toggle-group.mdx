## Uso

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"

<ToggleGroup type="multiple">
  <ToggleGroupItem value="bold" aria-label="Alternar negrita">
    <BoldIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

## Notas de uso

Construido sobre `ToggleGroup` de Radix. Las propiedades `variant` y `size` del
grupo se comparten con cada `ToggleGroupItem` mediante el contexto.

## Accesibilidad

- Con `type="single"`, los elementos se comportan como un grupo de opciones y
  las teclas de <kbd>flecha</kbd> desplazan la selección.
- Con `type="multiple"`, cada elemento se alterna de forma independiente y
  expone `aria-pressed`.
- <kbd>Tab</kbd> lleva el foco al grupo y las teclas de <kbd>flecha</kbd> lo
  desplazan entre sus elementos. Los que solo tienen icono necesitan un
  `aria-label`.
