## Accesibilidad

- Expone `aria-pressed` para que se anuncie su estado activado o desactivado.
- Se alterna con <kbd>Espacio</kbd> o <kbd>Intro</kbd> cuando tiene el foco y se
  alcanza con <kbd>Tab</kbd>.
- Los botones que solo muestran un icono necesitan un `aria-label` como nombre
  accesible.
