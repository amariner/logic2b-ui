## Uso

```tsx
import { TreeItem, TreeView } from "@/components/ui/tree-view"

<TreeView aria-label="Archivos" defaultExpanded={["src"]}>
  <TreeItem value="src" label="src">
    <TreeItem value="button" label="button.tsx" />
    <TreeItem value="card" label="card.tsx" />
  </TreeItem>
  <TreeItem value="readme" label="README.md" />
</TreeView>
```

Anidar elementos `TreeItem` convierte un elemento en una rama. El chevrón, el
estado `aria-expanded` y la sangría se derivan de forma automática.

## Accesibilidad

- Sigue el [patrón Tree View de WAI-ARIA](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/).
- <kbd>Flecha arriba</kbd> y <kbd>Flecha abajo</kbd> recorren los elementos
  visibles; <kbd>Inicio</kbd> y <kbd>Fin</kbd> saltan al primero o al último.
- <kbd>Flecha derecha</kbd> expande una rama contraída y después entra en ella;
  <kbd>Flecha izquierda</kbd> contrae una rama expandida o lleva al nivel padre.
- <kbd>Intro</kbd> o <kbd>Espacio</kbd> seleccionan el elemento con foco y
  alternan las ramas.
- Los elementos exponen `aria-level`, `aria-expanded` y `aria-selected`; los
  desactivados usan `aria-disabled` y se omiten durante la navegación.
