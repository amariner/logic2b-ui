## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"

<Skeleton className="h-4 w-[250px]" />
```

## Usage notes

`Skeleton` renders a single `<div>` and forwards every native `<div>` prop.
Set its shape and size with `className`.
